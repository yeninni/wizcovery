# KT wiz 회원 집계 데이터

업로드된 두 엑셀을 가공한 실제 관측 집계입니다. 개별 원본 행 대신 연도·성별·연령대·지역별 집계를 사이트에서 조회합니다.

| 자료 | 원본 행 수 | 집계 단위 | 집단 수 |
|---|---:|---|---:|
| 연도별 구매회원 | 340,910 | 연도 × 성별 × 연령대 × 지역 | 3,931 |
| 회원 구성 | 664,023 | 성별 × 연령대 × 지역 | 982 |

제공 연도는 2017·2018·2019·2022·2023·2024·2025년입니다. 2020·2021년 자료는 없습니다. 회원 구성 파일에는 연도·기준일이 없습니다.

## 파일

- `fan-segments.json`: 웹용 집계, 출처·정의, 구매빈도 모델의 오프라인 평가 결과.
- `fan-data.xlsx`: 가공 엑셀. 요약, 구매회원 집단, 회원 구성, 모델 검증, 항목 정의, 원본 대조를 포함합니다.
- `purchase-cohorts.csv`: 구매회원 집단별 집계. Excel에서 열 수 있는 UTF-8 BOM 형식입니다.
- `membership-cohorts.csv`: 전체 회원 구성 집계.

출처 원본 파일 이름과 SHA-256은 JSON의 `meta.sources`에 있습니다. 두 원본의 행 수·구매횟수 합계·성별·연령대·지역 미상 수와 집계값을 대조했습니다.

## 지표 해석

- 원본 1행을 1회원 관측으로 취급합니다. 같은 속성의 행은 별개 회원일 수 있어 중복 제거하지 않았습니다.
- 연도 간 연결할 회원 ID가 없으므로 누적 관측 수는 고유 인원수와 다릅니다.
- 구매횟수는 원본 항목의 합계입니다. 주문 건수·티켓 수량·관람횟수 중 정확한 정의와 연도별 집계 종료일은 제공처 확인이 필요합니다.
- ‘2회 이상 비중’은 해당 연도의 구매회원 관측 안에서 계산합니다. 전체 회원의 구매 전환율이나 다음 연도 개인 재구매율을 뜻하지 않습니다.
- 지역 공란은 ‘미상’으로 유지했습니다. 2025년 지역 미상은 41,144건, 해당 연도 관측의 약 54.9%입니다.
- 연령대는 제공된 분류를 유지했습니다. 구매 당시 연령인지 등의 기준일은 미확인입니다.
- 회원 구성 자료는 연도별 구매율의 분모로 사용하지 않습니다.

## AI 평가와 기존 상품 데이터의 관계

2022~2024년 학습, 2025년 검증으로 구매회원 중 원본 구매횟수 2회 이상 여부를 분류했습니다. 선택된 그래디언트 부스팅 모델의 ROC-AUC는 약 0.561이며, 단순 집단별 평활 통계보다 개선되지 않았습니다. `model_evaluation`은 이 독립 실험의 결과입니다.

현재 사이트의 회원 필터·집계·요약·차트는 실제 집계값을 코드로 계산합니다. LLM 질의·요약 기능은 아직 연결하지 않았습니다. 상품·가격·재고·경기·매장 운영과 상품 온톨로지는 별도의 시연 데이터로 표시합니다. 티켓 구매 속성에서 굿즈 취향이나 재고를 추정하지 않습니다.

데이터셋 JSON 내려받기는 전체 회원 집계와 현재 상품 시뮬레이션을 함께 포함하며 `meta.sources`로 출처를 구분합니다. 화면의 JSON 미리보기는 회원 집계 표 각각 앞 20개만 표시합니다.
